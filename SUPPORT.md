# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please search the existing
issues before filing new issues to avoid duplicates. For new issues, file your bug or
feature request as a new Issue.

When reporting a bug, include your Windows version, GPU and driver version, the
DxTimingCaptureLibrary commit you built, and, if possible, a small `.etl` capture that
reproduces the problem.

For help and questions about using this project, please file an Issue.

For PIX on Windows questions, see the [PIX blog](https://devblogs.microsoft.com/pix/) and the
[DirectX Discord](https://discord.gg/directx).

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
